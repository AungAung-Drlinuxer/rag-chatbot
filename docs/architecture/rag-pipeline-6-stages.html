Enterprise RAG Pipeline — 6 Core Stages Architecture

Complete technical workflow: Ingestion, Embedding, Hybrid Vector Search, Cross-Encoder Rerank, Prompt Synthesis, and LLM Generation with Fallback

1 & 2: Ingestion & Embedding

  • • Multi-Source: Confluence, OpenProject, XWiki, Manual.
  • • Chunking: 800 tokens window, 10% overlap (80 tokens).
  • • Embedding: nomic-embed-text (768-dim) on local Ollama.
  • • Continuous Sync: Background Celery beat worker every 30m.

3 & 4: Hybrid Search & Rerank

  • • Vector Search: HNSW Cosine Index (m=16, ef_c=64, ef_s=64).
  • • Keyword Search: PostgreSQL GIN index on tsvector.
  • • RRF Fusion: Reciprocal Rank Fusion blends vector + FTS.
  • • Reranker: bge-reranker-base cross-encoder + 0.75 gate.

5 & 6: Prompt & Dual LLM

  • • Grounding: Strict prompt prevents hallucinations & enforces tables.
  • • Primary LLM: Cloud OpenRouter (Gemini, DeepSeek, GLM).
  • • Fallback: On-Premise Llama 3.2 1B if primary times out (15s).
  • • Delivery: Token-by-token SSE streaming to desktop chat UI.
