IT Help Chatbot — Production System Architecture

On-Prem RKE2 Cluster | LangGraph RAG + BM25s/PGVector Hybrid | OpenBao Vault | MetalLB Ingress

Multi-Channel Hybrid Retrieval

  • • Dense Semantic: PGVector with bge-m3 1024-dim cosine distance
  • • Lexical Keyword: In-memory BM25s Okapi (<1.5ms, zero GPU)
  • • Fusion & Rerank: Reciprocal Rank Fusion (k=60) + bge-reranker
  • • Confidence Gate: Blended threshold (0.75) for auto-answering vs caution

Agentic LangGraph & HITL

  • • State Graph: Classify → Retrieve → Gate → Tools → Approval → Answer
  • • Human-in-the-Loop: Auto-pauses on escalation, interrupts inside graph
  • • Cross-Pod Durability: Postgres Checkpointer persists across pod restarts
  • • Jira & SMTP: Creates Jira issue (ITHD) & alerts admins upon approval

Enterprise Security & Storage

  • • OpenBao HA: 3-Node Raft cluster, Kubernetes ServiceAccount auth
  • • Zero Hardcoded Secrets: 15 backend secrets loaded dynamically from Vault
  • • High Availability DB: CloudNativePG 3-node streaming replication
  • • Resilient Storage: TrueNAS Enterprise ZFS storage backed by iSCSI/NFS
